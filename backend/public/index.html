Importar beneficiarios desde Excel

Esta opción importa los registros del Excel hacia PostgreSQL local. Se importan solamente las filas cuyo campo Estado sea Aprobado. El valor de FIBE_Beneficiado se almacena como información referencial, pero no determina si el registro se importa.

Los RUT se almacenan usando formato normalizado, sin puntos: 12345678-9. Durante esta etapa de prueba se acepta un RUT con formato correcto aunque el dígito verificador del Excel presente una inconsistencia; el sistema mostrará una advertencia.

Columnas utilizadas: Rut_Apoderado, Nombre_Apoderado, Apellido_Paterno_Apoderado, Apellido_Materno_Apoderado, Fecha_Nacimiento_Apoderado, Direccion, Sector, Correo_Apoderado, Telefono_Apoderado, Nombre_Alumno, Apellido_Paterno_Alumno, Apellido_Materno_Alumno, Rut_Alumno, FIBE_Beneficiado, Renovacion_automatica, Establecimiento, Nivel_Educacional, Estado, Fecha_Postulacion, dia, hora, mesa, Fecha_entrega y entregado_por.
